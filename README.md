# Python installation
First, check if you already have Python: type `cmd` in the Windows search bar,
open it, type `python --version` and press Enter. If you see a version number,
skip to the next step.

If you don't have Python, download it from https://www.python.org/downloads/
and install it (on the first install screen, tick "Add Python to PATH" before
clicking Install).

Then, back in that same cmd window, type `pip install pillow` and press Enter.
Wait for it to finish, then you're ready to run the program.


# Gear System

This app helps you keep track of gear pictures for your game characters.

You pick an "Account", then a "Class", then an "Item" (like Mount, Weapon, etc).
Some items also ask you to pick a "Level". Once picked, you can add a picture
to it, remove it, or save your changes.

## How to open it
Just double-click `app.pyw`.
